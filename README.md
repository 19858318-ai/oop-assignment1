
# MiniMart Inventory System

## Description
A simple store inventory system using Python OOP.

## Files
- product.py: Defines the Product class.
- inventory.py: Manages the inventory.
- main.py: Runs the demonstration.

## How to Run
1. Install Python 3.10 or later.
2. Open a terminal in the project folder.
3. Run:

   python main.py

## Design Decisions
- A dictionary stores products using SKU as the key.
- Properties validate price and quantity.
- Class methods provide alternative constructors.
- A static method validates SKU codes.
- Computed properties return line value and low-stock status.
